How machine translation quietly changed the web

A sample article — move the mouse over a translated sentence to see the original.

For most of the internet's history, language was a hard border. A reader in Shanghai could not read a German forum thread, and a developer in Berlin could not read a Japanese API reference. Machine translation did not remove that border, but it made it porous.

The first generation of browser translators worked sentence by sentence, and they were honest about it: you hovered over a paragraph and the original sentence appeared in a small white bubble. That gesture is what this page brings back.

What the old widget did

Google's website translator replaced the text of a block element with its translation and kept the original in memory. When you moved the mouse over the translated sentence, a tooltip fetched the source text and displayed it above the paragraph.

Readers trusted the translation more when they could check it, one sentence at a time.

The widget on this page is a rewrite of that behaviour. It talks to the same translation service, but it keeps the source text attached to every translated fragment, so the tooltip is instant: no second request, no waiting.

Things it handles

  • Text inside links, emphasis and inline code keeps working.
  • Dynamic content added later is translated automatically.
  • Switching language restores the page instead of translating the translation.
  • Long documents are batched into a few requests and cached in localStorage.

Use the switcher in the top-right corner to change the target language, or pick the original from it to get the page back exactly as it was written.
